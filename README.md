# Minesweeper in Java

A simple Minesweeper game built from scratch using Java. 

## A Quick Disclaimer ⚠️
* **Beginner Code**: I am a complete Java beginner, so the code is not very Object-Oriented (OOP) styled.
* **Highly Inefficient**: I started writing the project with a 1D array, moved to a 2D array, and kept converting the main array back and forth between 1D and 2D. It is a bit messy and stupidly optimized, but it works!
* **No Flags Yet**: The game does not have a flag feature right now, so please suffice!

## How to Clone and Play

Follow these simple steps to download and launch the game from your terminal:

### 1. Clone the Repository
Run the following command to download the game code:
```bash
git clone https://github.com/Ayush00101/minesweeper.git
```

### 2. Open the Folder
Navigate into the cloned project directory:
```bash
cd minesweeper
```

### 3. Run the Game
Launch the game directly using the Java single-file runner:
```bash
java game.java
```
